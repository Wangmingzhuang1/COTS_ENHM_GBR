## Environmental source-data format

`environment_maps.npz` uses separate latitude/longitude arrays for each provider grid. Variables include annual rainfall negative-minus-positive contrast (mm/year), chlorophyll negative-minus-positive contrast (mg/m³), and negative, positive and difference fields for surface northward velocity (m/s). Load using `numpy.load(path, allow_pickle=False)`; NaNs preserve the original masks. Coordinate grids must not be interchanged.

`reef_current_phase_composites.csv` samples nearest grid cells at the 113 reef locations; locations sharing a grid cell are not independent hydrodynamic observations. `environment_metadata.json` lists the complete years and phase memberships actually used. `southward_weakening_percent` is reported only when both regional means are southward; negative values denote strengthening. No parcel pathways, residence time or settlement flux were calculated from these composites.
